# Đường ống Dữ liệu & ETL

This directory contains resources for orchestrating data movement.
*Thư mục này chứa các tài nguyên để điều phối quá trình di chuyển dữ liệu.*

- **SQL Upsert (MERGE):** See `docs/06-warehousing/02_incremental_etl_merge.sql`.
- **Airflow / dbt:** In a true enterprise environment, the SQL scripts provided in this repository would be orchestrated by Apache Airflow (for scheduling) and dbt (for data transformations).
  *(Trong môi trường thực tế, các tập lệnh SQL trong repo này sẽ được lập lịch bởi Apache Airflow và xử lý chuyển đổi bằng dbt).*
