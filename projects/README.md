## Enterprise Bank Architecture (Kiến trúc Ngân hàng Doanh nghiệp)
1. **Schema:** Design an OLTP schema in 3NF for a Bank (Users, Accounts, Transactions).
2. **Integration:** Write a PL/SQL Package for transferring funds with strict exception handling and Row-Level Locks (`FOR UPDATE`).
3. **High Availability:** Spin up an Oracle Data Guard environment and successfully perform a Switchover.
4. **Analytics:** Design a Star Schema and build a Materialized View with `FAST REFRESH` to aggregate daily transaction volumes.
5. **Incident Handling:** Identify and resolve an intentional Deadlock (ORA-00060).
