# 📊 Architecture Diagrams
# Sơ đồ Kiến trúc

This folder contains the architectural blueprints of the mission-critical systems described in this roadmap.
*Thư mục này chứa các bản thiết kế kiến trúc của các hệ thống trọng yếu được mô tả trong lộ trình này.*

## Technologies Used
The diagrams are written as **PlantUML** code (`.puml`). You can render them using the PlantUML plugin in VSCode, IntelliJ, or online at [PlantText](https://www.planttext.com/).
*(Các sơ đồ được viết dưới dạng mã PlantUML. Bạn có thể render chúng bằng plugin trong VSCode hoặc trên web).*
